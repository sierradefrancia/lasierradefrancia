# Interior y economía doméstica

Fuentes Hernández (2024, pp. 18–19), siguiendo a González Iglesias (1982), describe dormitorios en primera planta y cocina en la segunda. Registra un sistema de secado de castañas sobre la cocina, un hogar protegido con losas graníticas y corredores útiles para ventilar fruta. Se trata de una organización documentada en su estudio, no de una planta universal.

## Vocabulario documentado

| Voz | Función referida |
|---|---|
| Cachas | Bastidores de madera vinculados al secado |
| Cintas | Listones relacionados con los bastidores |
| Llar | Elemento suspendido del hogar para el caldero |
| Tallizo | Apoyo para la leña |
| Tizneros | Apoyos pétreos para utensilios de cocina |

La fuente inmediata es el TFG; la descripción de González Iglesias no se ha cotejado directamente. El vocabulario se conserva como pista etnográfica, pendiente de contraste oral y lexicográfico.

El hogar, la reserva de combustible y el secado muestran cómo una vivienda podía integrar preparación de alimentos y almacenamiento estacional. Queda por estudiar el reparto de tareas, la ventilación, las diferencias económicas y la transformación de estos usos. No se generaliza una única organización familiar.
