
# La Sierra de Francia

**Conocer, comprender, preservar y compartir la Sierra de Francia y su entorno.**

[www.lasierradefrancia.es](https://www.lasierradefrancia.es)

## Sobre el proyecto

La Sierra de Francia es un proyecto independiente de investigación, documentación y divulgación dedicado al conocimiento de la Sierra de Francia, en Salamanca (España), y de los territorios relacionados con ella.

Nuestro propósito es construir una base de conocimiento abierta, rigurosa, accesible y en permanente evolución.

El proyecto abarca:

- Pueblos y conjuntos históricos.
- Historia y evolución del territorio.
- Cultura, tradiciones y patrimonio.
- Arquitectura y urbanismo tradicional.
- Geografía, geología y paisajes.
- Flora, fauna y ecosistemas.
- Parque Natural Las Batuecas–Sierra de Francia.
- Rutas, senderos y turismo cultural.
- Territorios relacionados, especialmente Las Hurdes y Ciudad Rodrigo.
- Artículos e investigaciones monográficas.

## Filosofía editorial

La calidad del conocimiento es nuestra prioridad.

Cada sección debe ofrecer información útil, contextualizada y suficientemente desarrollada.

Las investigaciones que requieran mayor profundidad se publicarán como artículos monográficos dentro de sus correspondientes secciones temáticas.

Los artículos podrán relacionarse entre sí y aparecer en índices generales, manteniendo una única ubicación canónica.

### Principios

1. Priorizar fuentes primarias y publicaciones académicas.
2. Distinguir hechos documentados, interpretaciones, hipótesis y tradiciones.
3. Proporcionar referencias y enlaces a las fuentes originales.
4. Reconocer las incertidumbres y los límites de la evidencia.
5. Corregir los errores de forma transparente.
6. Preservar la coherencia histórica, territorial y científica.
7. Evitar contenidos superficiales, duplicados o creados únicamente para posicionamiento SEO.
8. Mantener el conocimiento accesible para personas y sistemas de inteligencia artificial.

## Organización del conocimiento

La web se organiza en grandes áreas territoriales y temáticas.

Cada pueblo podrá disponer de:

- Índex.
- Historia.
- Cultura y tradiciones.
- Arquitectura.
- Patrimonio histórico.
- Geografía y entorno.
- Turismo.

Los artículos especializados se integrarán dentro de la sección correspondiente.

La web dispondrá también de un índice general de artículos e investigaciones.

## Tecnología

El proyecto utiliza:

- GitHub como repositorio.
- GitHub Pages para su publicación.
- Jekyll como generador estático.
- Just the Docs como tema.
- Markdown para los contenidos.

Se incorporarán herramientas de indexación, metadatos estructurados y documentación orientada a sistemas de IA.

## Publicación con GitHub Pages

La web se publicará mediante GitHub Actions.

Configuración prevista:

1. Abrir `Settings` del repositorio.
2. Entrar en `Pages`.
3. Seleccionar `GitHub Actions` como fuente de publicación.
4. Incorporar el workflow de despliegue en `.github/workflows/pages.yml`.
5. Publicar los cambios en la rama `main`.

El workflow compilará el sitio Jekyll y desplegará el resultado en GitHub Pages.

El dominio personalizado se configurará cuando la estructura técnica esté preparada.
